Mineração de Dados - Dashboard e infografico 
Instruções: analisar as base de dados disponibilizada e apresentar as devidas conclusões , insights e padrões encontrados , E com isso construir um dashboard e um infográfico

DASHBOARD: 📈
•Escolher uma ferramenta de BI e apresentar as analise de dados – construindo um Dashboard com os principais indicadores (pelo menos 10 gráficos com informações diferentes mas que tenham relação / sentido ).

INFOGRÁFICO: 🎨

•Vocês terão que criar um Infográfico – destacando as conclusões tomadas das bases de dados disponibilizadas, insights padrões e recomendações – como sendo um cientista de dados
